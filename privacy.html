Privacy policy

Last updated: 8 November 2026

Feelascope publishes animated parenting videos. The "Feelascope Uploader" app is an internal tool used only by Feelascope to upload its own videos to its own YouTube channel and social media accounts.

What data the app uses

The app uses Google's YouTube Data API, the TikTok Content Posting API and the Meta Graph API to upload videos, titles, captions and thumbnails to Feelascope's own YouTube channel, TikTok account, Instagram account and Facebook page. It only reads the basic profile information needed to post (account ID, display name, posting settings). It only accesses the Feelascope accounts that authorised it. It does not access, collect, store or share data of any other user.

Storage and sharing

Access tokens are stored encrypted and used only to publish Feelascope's own content. No personal data is sold or shared with third parties.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions (Google) or in the TikTok app under Settings → Security → Manage app permissions.

Feelascope's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Uploads use the YouTube Terms of Service and the Google Privacy Policy.
